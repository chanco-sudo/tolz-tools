# Tolz.org — Free Online Tools

**Tolz.org** is a collection of free, easy-to-use online tools for everyday tasks — no sign-up required.

🔗 **Website:** [https://www.tolz.org/](https://www.tolz.org/)

## What's available

- 🖼️ **Image Tools** — Compress, convert, and generate ID photos
- 📄 **PDF Tools** — Merge, split, compress, and convert PDF to Word
- 🧮 **Calculators** — Health, construction, and everyday-life calculators
- 🔗 **URL Tools** — Shorten and manage links
- ✏️ **Text Tools** — Word counter, sentence counter
- 🎨 **Design Tools** — Color picker, QR code generator
